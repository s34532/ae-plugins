# Volumetric Cloud Shader

Native After Effects volumetric weather shader with AE camera integration, manual camera controls,
cloud layers and towers, rain and virga, lighting controls, wind animation, and continuous day cycles.

![Volumetric Cloud preview](cloud-preview.jpg)

- `VolumetricCloudShader.cpp` — effect implementation
- `VolumetricCloudShader.r` / `.rc` — After Effects PiPL resources
- `VolumetricCloudShader.aex` — ready-to-install Windows build
