# ASCII Art Converter

Converts footage into antialiased ASCII typography using the built-in VGA face or fonts installed on
the user's Windows system.

Features include character sizing up to 128, font styles, preset density ramps, cell aspect, tracking,
line spacing, monochrome or source color, directional ASCII edge glyphs, reveal, character cycling,
scramble, glitch, temporal stability, and real 8/16-bpc rendering.

- `ASCIIArtConverter.cpp` — effect implementation
- `ASCIIArtConverter.r` — After Effects PiPL resource
- `ASCIIArtConverter.aex` — ready-to-install Windows build
